# ربات نوسان‌یاب طلا (Rust + Teloxide)

قیمت چند طلافروشی را **هم‌زمان** پایش می‌کند و وقتی نوسان شدید اتفاق بیفتد،
به کاربرانی که `/start` کرده‌اند پیام می‌دهد:
- **افزایش شدید** → «فرصت فروش»
- **کاهش شدید** → «فرصت خرید»

دستورها: `/start` `/stop` `/price` `/help`

## اجرا
1. `cp .env.example .env` و گذاشتن توکن از @BotFather
2. آدرس و سلکتور طلافروشی‌ها را در `src/sources.rs` تنظیم کن
3. `cargo run --release`
4. تست‌ها: `cargo test`

اگر cargo از نسخه‌ی rustc شکایت کرد: `rustup update stable`

## شبکه در ایران (تلگرام فیلتر، سایت‌ها فقط از داخل)
تلگرام و سایت‌های قیمت مسیر شبکه‌ی **جدا** دارند، پس لازم نیست VPN سراسری روشن باشد:
- `TELEGRAM_PROXY` — فقط ترافیک تلگرام از این پروکسی رد می‌شود. آدرس پروکسی محلیِ کلاینت VPN را بگذار،
  مثلاً `socks5h://127.0.0.1:10808` یا `http://127.0.0.1:7890` (پورت را از تنظیمات کلاینت بردار).
- `SITES_PROXY` — اختیاری؛ فقط اگر برنامه روی سرور خارج از ایران اجرا می‌شود و باید سایت‌ها از پروکسی ایرانی رد شوند.
- سایت‌های قیمت پیش‌فرض **مستقیم** وصل می‌شوند و `HTTP_PROXY`/`ALL_PROXY` سیستم را نادیده می‌گیرند.
- اگر VPN سراسری (TUN) داری، در کلاینت VPN قانون «ترافیک ایران مستقیم» (bypass Iran / geoip:ir) را فعال کن.

## نحوه‌ی تشخیص نوسان
- هر `CHECK_INTERVAL_SEC` ثانیه همه‌ی منابع **هم‌زمان** (با timeout ده‌ثانیه‌ای) گرفته می‌شوند.
- قیمت فعلی با **کمینه/بیشینه‌ی پنجره‌ی لغزان** (`WINDOW_MINUTES`) مقایسه می‌شود؛
  اگر از `FLUCT_THRESHOLD` درصد بیشتر باشد، نوسان حساب می‌شود.
- **تأیید:** نوسان باید در `CONFIRM_TICKS` چک پشت‌سرهم دیده شود.
- **sanity:** تغییر تک‌مرحله‌ای بیشتر از `MAX_JUMP_PCT` تا تأیید در چک بعدی نادیده گرفته می‌شود
  (جلوگیری از هشدار دروغ به‌خاطر خطای پارس یا تغییر ساختار سایت).
- **cooldown** برای هر منبع و هر جهت جداست (`ALERT_COOLDOWN_SEC`).
- هشدارهای یک چک در **یک پیام** تجمیع می‌شوند.
- کاربری که ربات را بلاک کند خودکار از لیست حذف می‌شود.

## افزودن طلافروشی جدید
در `src/sources.rs` یک `Source` با نام (یکتا)، آدرس و سلکتور CSS عنصر قیمت اضافه کن.
اگر عنصر چند عدد دارد («۱۸ عیار ۳,۲۵۰,۰۰۰») بزرگ‌ترین عدد به‌عنوان قیمت برداشته می‌شود،
ولی سلکتور دقیق‌تر همیشه بهتر است.
